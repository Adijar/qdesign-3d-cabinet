# Qdesign — 3D-конфигуратор тумбы

Интерактивная 3D-модель тумбы на Three.js и Vite.

## Возможности
- Изменение ширины, высоты и глубины в миллиметрах.
- Вращение и масштабирование через OrbitControls.
- Три материала: белый, серый, орех.
- Свет, тени, пол и сетка.
- Дверца, ручка и внутренняя полка.
- Адаптивный интерфейс для мобильных устройств.

## Запуск локально

Нужен установленный Node.js (рекомендуется LTS).

```bash
npm install
npm run dev
```

Откройте URL, который покажет Vite, обычно `http://localhost:5173`.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Публикация на Vercel
1. Загрузите папку проекта в новый GitHub-репозиторий.
2. Войдите в Vercel и импортируйте этот репозиторий.
3. Framework Preset: Vite.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Нажмите Deploy.

При следующих `git push` Vercel обычно автоматически обновляет сайт.
